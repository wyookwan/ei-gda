# คู่มือสั้นสำหรับการนำร่อง

ทุกบทบาทเข้าระบบแล้วเลือก **หน่วยงานที่กำลังทำงาน** จากช่องเลือกที่แถบด้านบน ถ้าบัญชีผูกกับหลายหน่วยงาน
งานที่สร้างจะเป็นของหน่วยงานที่เลือกไว้ และแก้ไขได้เฉพาะเมื่อเลือกหน่วยงานนั้นอยู่

สถานะของงานเดินตามลำดับนี้ แสดงเป็นแถบที่หน้า "ส่งงานและติดตาม"

ฉบับร่าง → ส่งครั้งแรก → มอบหมายกรรมการ → อยู่ระหว่างทบทวน → ขอหลักฐานเพิ่ม → ส่งฉบับแก้ไข → ทบทวนซ้ำ → ยืนยันผล

สถานะของงานแยกจากสถานะของแต่ละประเด็น (เปิดอยู่ / ตอบกลับแล้ว รอผู้ตรวจ / ปิดแล้ว)

## ผู้ประสานรอบ สป.อว.

1. **เมนู ชุดเกณฑ์:** ตรวจว่าชุดเกณฑ์ที่จะใช้มีสถานะ "เผยแพร่แล้ว" การอนุมัติชุดเกณฑ์แยกจากการยืนยันแหล่งอ้างอิง
   ชุดเกณฑ์ที่มีป้าย DEMO อนุมัติในสภาพแวดล้อมสาธิต และไม่ใช่การรับรองจาก อว. หรือ สป.อว.
2. **เมนู รอบประเมินของหน่วยงาน → เปิดรอบประเมินใหม่:** เลือกชุดเกณฑ์ที่เผยแพร่แล้ว
   ระบบตรึงเวอร์ชันของชุดเกณฑ์ไว้กับรอบนั้น
3. **จัดการรอบ → เชิญหน่วยงาน:** เลือกผู้ประสานงานสถาบันและวันครบกำหนด ระบบแจ้งเตือนผู้ประสานงานสถาบัน
4. เมื่อหน่วยงานส่งงาน เปิด "มอบหมาย / ติดตาม" แล้วเลือกกรรมการ ถ้าต้องถอนสิทธิ์ ให้กด "ถอนสิทธิ์" พร้อมเหตุผล
   สิทธิ์ของกรรมการคนนั้นสิ้นสุดทันที ทั้งหน้าจอและลิงก์ตรง
5. **Dashboard:** แสดงตัวหาร (จำนวนหน่วยงานที่ตอบรับ), จำนวนที่ส่ง, จำนวนที่ยืนยันผลแล้ว, งานที่เกินกำหนด, ประเด็นสำคัญมากที่ยังเปิด และหัวข้อที่พบซ้ำ
   ส่งออก CSV ได้ ส่วน "ข้อมูลเตรียมส่ง Digital Single View" ยังไม่ส่งไปยังระบบจริง
6. **ปิดรอบ:** ปิดแบบสมบูรณ์ได้เมื่อทุกหน่วยงานยืนยันผลครบและไม่มีประเด็นสำคัญมากค้าง
   ถ้ายังไม่ครบ ให้ปิดแบบ "ยังไม่สมบูรณ์" พร้อมเหตุผล

ผู้ประสานรอบเห็นสถานะของงาน แต่ไม่เปิดเอกสารต้นฉบับ เว้นแต่ผู้ดูแลระบบให้สิทธิ์ "อ่านต้นฉบับ" แยกไว้
ผู้บริหารเห็นเฉพาะ Dashboard แบบสรุป

## เจ้าหน้าที่มหาวิทยาลัย (ผู้ประสานงานสถาบันและเจ้าหน้าที่ที่ได้รับสิทธิ์)

1. **ผู้ประสานงานสถาบัน:** เปิดเมนู รอบประเมินของหน่วยงาน แล้วกด "ตอบรับเข้าร่วม"
2. กด **เริ่มงานประเมินในรอบนี้** โดยระบุชื่องานและประเภทหน่วยงาน แล้วกรอก AI Use Case ประเภทข้อมูล และผลต่อการตัดสินใจ
   ถ้าเป็นการคัดกรองผู้สมัคร ให้เลือก "AI ช่วยคัดกรองผู้สมัคร" ซึ่งเป็นคนละกรณีกับการเรียนการสอน
3. ยืนยันขอบเขต Control แล้วแนบหลักฐาน PDF โดยต้องเลือกให้ครบทุกไฟล์:
   - **ชั้นข้อมูล:** เผยแพร่ได้ / ใช้ภายใน / ไม่เปิดเผย ระบบไม่รับเอกสารชั้นความลับราชการ
   - **ข้อมูลส่วนบุคคล:** ไม่มี / มี / มีข้อมูลอ่อนไหว / ยังไม่ทราบ
   - **ปกปิดข้อมูลแล้ว:** ถ้าปกปิดแล้ว ให้ทำเครื่องหมาย

   รอบนำร่องรับเฉพาะเอกสารเผยแพร่หรือเอกสารที่ปกปิดข้อมูลแล้ว
   เอกสารที่ไม่มีสิทธิ์ส่งให้โมเดลจะไม่ถูกส่ง ระบบจะประเมินจากตำแหน่งหลักฐานเท่านั้น และแจ้งเหตุผลไว้
4. หน้า **ส่งงานและติดตาม** → "ส่งงานครั้งแรก" ระบบบันทึกเป็นฉบับที่ 1 และล็อกงานไว้จนกว่ากรรมการจะส่งกลับ
5. เมื่อได้รับแจ้งเตือน "มีคำขอหลักฐานเพิ่ม":
   - อ่านประเด็นแต่ละข้อ (Control, เหตุผล, หลักฐานที่ต้องการ, กำหนดส่ง)
   - กด "แนบหลักฐานใหม่"
   - กลับมาเขียนคำชี้แจงทุกประเด็น
   - กด "ส่งฉบับแก้ไข"

   ฉบับก่อนหน้าและไฟล์เดิมยังเก็บไว้ครบ ฉบับใหม่แสดงไฟล์ที่เพิ่มหรือนำออก
6. **เมนู ทะเบียน AI:** บันทึกระบบ AI ของหน่วยงาน (เจ้าของ วัตถุประสงค์ ผู้ได้รับผลกระทบ ผู้ให้บริการ/โมเดล ประเภทข้อมูล ความเสี่ยง รอบทบทวน) และเชื่อมกับงานประเมินที่เป็นหลักฐานการปฏิบัติ

## กรรมการ

1. **เมนู คิวทบทวนของกรรมการ:** แสดงงานที่ได้รับมอบหมาย ประเด็นที่ยังเปิด ประเด็นที่รอคุณตรวจ และป้าย "หลักฐานใหม่" เมื่อมีฉบับแก้ไข
2. เปิดงานแล้วกด **เริ่มทบทวน** ตารางจะแสดง "ผลเบื้องต้นของระบบ" คู่กับ "ผลที่กรรมการยืนยัน" แยกกัน
3. **เปิดประเด็นใหม่:** ระบุ Control, ความสำคัญ, เหตุผล, หลักฐานที่ต้องการ, ผู้รับผิดชอบฝั่งหน่วยงาน และกำหนดส่ง
   คุณจะเป็นผู้ยืนยันการปิดประเด็นนั้น จากนั้นกด **ขอหลักฐานเพิ่ม**
4. เมื่อหน่วยงานส่งฉบับแก้ไข กด **เริ่มทบทวนซ้ำ** แล้วทำอย่างใดอย่างหนึ่ง:
   - **ปิดประเด็นด้วยหลักฐาน:** เลือกไฟล์และเลขหน้าที่ใช้ปิด พร้อมเหตุผล
   - **เปิดประเด็นอีกครั้ง:** ถ้ายังไม่พอ
5. **บันทึกผลของกรรมการ:** เลือก หลักฐานเพียงพอ / ขอหลักฐานเพิ่ม / ไม่เข้าเงื่อนไข พร้อมเหตุผล
   ต้องบันทึกให้ครบสำหรับ Control วิกฤตและ Control ที่มีประเด็น
6. กด **ยืนยันผลการประเมิน** ระบบจะไม่ยอมยืนยันถ้ายังมีประเด็นระดับสำคัญมากที่ยังไม่ปิด

เมื่อถูกถอนสิทธิ์ งานจะย้ายไปอยู่ใต้หัวข้อ "สิทธิ์ที่สิ้นสุดแล้ว" และเปิดงานหรือหลักฐานไม่ได้อีก

ถ้าเห็นข้อความ "ข้อมูลถูกเปลี่ยนจากหน้าจออื่นแล้ว" แปลว่ามีอีกหน้าจอหนึ่งดำเนินการก่อน ให้โหลดหน้าใหม่ ระบบไม่ได้บันทึกซ้ำ
